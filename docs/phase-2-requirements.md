# Phase 2 - Requirement Analysis
## Functional requirements
- Capture username, user ID, age, weight, goal and intensity.
- Generate a 7-day plan.
- Generate a concise nutrition/recovery tip.
- Accept feedback and create a revised plan.
- Store original and updated plans.
- Provide an admin view.

## Non-functional requirements
Responsive UI, persistent SQLite storage, modular FastAPI backend, environment-based API key, automated tests.
